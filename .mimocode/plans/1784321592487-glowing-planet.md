# Fix: MT4 FILE_COMMON Path Derivation for Portfolio Deployment

## Problem

The MT4 connector EA uses `FILE_COMMON` flag (`CertusFileWriter.mqh:14`), which makes MT4 write output files to:
```
...\MetaQuotes\Terminal\Common\Files\Certus\
```

But the current `DeriveMT4PathAsync` assumes the connection's `FilePath` is per-terminal (`Terminal\<hash>\Certus\`), causing it to derive:
```
...\MetaQuotes\Terminal\Common\Files\MQL4\Experts\   ← WRONG
```
When it should find:
```
...\MetaQuotes\Terminal\<hash>\MQL4\Experts\          ← CORRECT
```

Additionally, `ActivateEAsAsync` writes `certus_activation.json` to `<mt4DataPath>\Files\Certus\` (per-terminal), but the EA reads it from `Common\Files\Certus\` via `FILE_COMMON`.

## Approach

Detect Common vs per-terminal path by checking if the connection FilePath contains `Common\Files\`. For Common paths, scan `MetaQuotes\Terminal\` for hash subdirectories containing `MQL4\Experts\`.

## Changes

### 1. `src/Certus.Application/Platform/DTOs/DeriveMT4PathResult.cs`

Add fields to support multi-terminal discovery:
- `IsCommonPath` (bool) — true when FILE_COMMON path detected
- `CommonFilesPath` (string?) — the `Common\Files\Certus\` directory path
- `TerminalCandidates` (List<TerminalCandidate>) — discovered terminals

Add `TerminalCandidate` record:
```csharp
public record TerminalCandidate
{
    public string MT4DataPath { get; init; }
    public string ExpertsPath { get; init; }
    public string DisplayName { get; init; }
}
```

### 2. `src/Certus.Application/Platform/PortfolioDeploymentService.cs`

**Replace `DeriveMT4PathAsync`** — detect Common vs per-terminal, dispatch to helper:
- If path contains `Common\Files\` → `DeriveFromCommonPathAsync`
- Otherwise → `DeriveFromTerminalPathAsync` (extracted current logic)

**New `DeriveFromCommonPathAsync`:**
1. Navigate up from `Common\Files\Certus\` to `MetaQuotes\` root
2. Scan `MetaQuotes\Terminal\` for hash subdirs with `MQL4\Experts\`
3. 1 found → auto-select, Success=true
4. Multiple found → return all as `TerminalCandidates`, Success=false (UI must prompt)
5. 0 found → error

**New `DeriveFromTerminalPathAsync`:** — existing logic extracted unchanged.

**Fix `ActivateEAsAsync`** — use `CommonFilesPath` when available (FILE_COMMON), fallback to per-terminal.

**Fix `DeployAsync`** — handle new `SelectedTerminalPath` field from request.

### 3. `src/Certus.Application/Platform/DTOs/DeployPortfolioRequest.cs`

Add `SelectedTerminalPath` (string?) — user-selected terminal when multiple candidates found.

### 4. `src/Certus.Dashboard/Components/Shared/DeployPortfolioDialog.razor`

**Step 2 UI:** When `TerminalCandidates.Count > 1`, show a `MudSelect` dropdown for terminal selection.

**State:** Add `_selectedTerminalPath` field, wire through `CheckConflictsAndNext()` and `Deploy()`.
