# Fix Docker Port 8080 — Database Initialization

## Root Cause

The `MigrateWithBootstrapAsync` method in `Program.cs` crashes on fresh Docker because:

1. **No database exists** — SQL Server starts empty; the connection string points to `Database=Certus` which doesn't exist yet. The code tries `connection.OpenAsync()` against a non-existent database → `SqlException: Cannot open database "Certus"`.

2. The original bootstrap logic (check `__EFMigrationsHistory`, insert `InitialCreate` if missing) was added purposefully to handle the case where `EnsureCreated()` created tables without recording migration history. It must be preserved.

3. My earlier fix incorrectly removed the bootstrap logic AND placed raw SQL database-creation code directly in `Program.cs`, which violates the architecture: **Infrastructure owns persistence**, Program.cs is just DI wiring.

## Fix

Move `MigrateWithBootstrapAsync` into the Infrastructure layer and add database-creation logic before the existing bootstrap.

### Files to modify

| File | Change |
|------|--------|
| `src/Certus.Infrastructure/Persistence/DatabaseInitializer.cs` | **New file.** Static class with `InitializeAsync(CertusDbContext db)` containing: (1) connect to `master`, create database if missing, close; (2) original bootstrap logic: check `__EFMigrationsHistory` + `InitialCreate`, create table + insert if missing; (3) `db.Database.MigrateAsync()` |
| `src/Certus.Dashboard/Program.cs` | Replace inline `MigrateWithBootstrapAsync` with a call to `DatabaseInitializer.InitializeAsync(db)`. Remove the `using Microsoft.EntityFrameworkCore;` import if no longer needed by Program.cs (check). |

### DatabaseInitializer logic (preserves existing bootstrap + adds DB creation)

```csharp
static async Task MigrateWithBootstrapAsync(CertusDbContext db)
{
    // 1. Ensure database exists (new — fixes Docker)
    var connectionString = db.Database.GetConnectionString();
    if (!string.IsNullOrEmpty(connectionString))
    {
        var sb = new SqlConnectionStringBuilder(connectionString);
        var databaseName = sb.InitialCatalog;
        sb.InitialCatalog = "master";
        using var masterConn = new SqlConnection(sb.ConnectionString);
        await masterConn.OpenAsync();
        using var checkCmd = masterConn.CreateCommand();
        checkCmd.CommandText = $"SELECT COUNT(*) FROM sys.databases WHERE name = '{databaseName}'";
        var dbExists = (int)checkCmd.ExecuteScalar()! > 0;
        if (!dbExists)
        {
            using var createCmd = masterConn.CreateCommand();
            createCmd.CommandText = $"CREATE DATABASE [{databaseName}]";
            await createCmd.ExecuteNonQueryAsync();
        }
        await masterConn.CloseAsync();
    }

    // 2. Bootstrap migration history (existing — preserved exactly)
    var connection = db.Database.GetDbConnection();
    await connection.OpenAsync();
    // ... original __EFMigrationsHistory check + InitialCreate insert logic ...
    await connection.CloseAsync();

    // 3. Apply pending migrations
    await db.Database.MigrateAsync();
}
```
