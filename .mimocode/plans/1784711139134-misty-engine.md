# Plan: StrategyMapping Table for EA-to-Strategy Linkage

## Problem

Trade `9a3e0b43-6151-424a-a36b-242e3d3c08a5` has `StrategyId = 00000000-...` because `FindOrCreateStrategyMappingAsync` (`PlatformService.cs:368-373`) is a stub returning `Guid.Empty`. All imported trades are affected.

## Workflow: Spec → Tests → Implementation

Following project rules: **No spec, no code. No tests, no merge.**

---

## Phase 1: Spec

Create `specs/features/strategy-mapping.md`

### Functional Requirements
- FR-001: A `StrategyMapping` entity links `(ConnectionId, StrategyExternalId)` to a `StrategyDefinition.Id`
- FR-002: Each mapping is unique per (ConnectionId, StrategyExternalId)
- FR-003: When importing a trade, `FindOrCreateStrategyMappingAsync` looks up existing mapping or creates a new one
- FR-004: If no `StrategyDefinition` exists for the EA name, one is auto-created with type `ExpertAdvisor`
- FR-005: Existing trades with `StrategyId = Guid.Empty` can be re-linked after mapping is created

### Acceptance Criteria
- AC-001: Given a connection and EA name with no existing mapping, when `FindOrCreateStrategyMappingAsync` is called, then a new `StrategyDefinition` and `StrategyMapping` are created, and the strategy ID is returned
- AC-002: Given a connection and EA name with an existing mapping, when `FindOrCreateStrategyMappingAsync` is called, then the existing `StrategyDefinition.Id` is returned without creating duplicates
- AC-003: Given an empty `strategyExternalId`, when `FindOrCreateStrategyMappingAsync` is called, then `Guid.Empty` is returned
- AC-004: Given a `StrategyMapping` with a known EA name, when the entity is created with duplicate `(ConnectionId, StrategyExternalId)`, then a domain error is raised
- AC-005: The `StrategyMapping` entity exposes `ConnectionId`, `StrategyExternalId`, `StrategyDefinitionId`, and `CreatedAt`

## Phase 3: Implementation

### 3a. Domain Layer

**Create** `src/Certus.Domain/Platform/Entities/StrategyMapping.cs`

```csharp
public class StrategyMapping : Entity
{
    public Guid ConnectionId { get; private set; }
    public string StrategyExternalId { get; private set; } = string.Empty;
    public Guid StrategyDefinitionId { get; private set; }
    public DateTime CreatedAt { get; private set; }

    private StrategyMapping() { }

    public StrategyMapping(Guid id, Guid connectionId, string strategyExternalId, Guid strategyDefinitionId) : base(id)
    {
        ConnectionId = connectionId;
        StrategyExternalId = strategyExternalId;
        StrategyDefinitionId = strategyDefinitionId;
        CreatedAt = DateTime.UtcNow;
    }
}
```

**Create** `src/Certus.Domain/Platform/Repositories/IStrategyMappingRepository.cs`

```csharp
public interface IStrategyMappingRepository
{
    Task<StrategyMapping?> GetByConnectionAndExternalIdAsync(Guid connectionId, string strategyExternalId);
    Task<IReadOnlyList<StrategyMapping>> GetByConnectionIdAsync(Guid connectionId);
    Task AddAsync(StrategyMapping mapping);
}
```
