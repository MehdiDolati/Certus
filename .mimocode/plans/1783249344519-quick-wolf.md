# Plan: Testing the MQ4 Expert Advisor

## The Problem

The EA is MQ4 code running inside MetaTrader 4. We cannot unit test it with xUnit/.NET. Testing must be split into two layers:

1. **Certus side** (testable with .NET) — parsing, importing, file watching
2. **EA side** (manual/integration) — MT4 terminal, order execution

## Testing Strategy

### Layer 1: Certus-Side Tests (Automated, .NET)

These test that Certus correctly handles the EA's output.

#### 1.1 JSON Parser Tests
- Create sample `portfolio_status.json` and `trades.json` fixture files matching the EA spec schemas
- Test Mt4JsonParser against these fixtures
- Test edge cases: missing fields, wrong types, empty arrays, null values

#### 1.2 Integration Tests
- Write sample JSON files to disk
- Test FileImportService detects changes
- Test PlatformService imports data correctly
- Test duplicate trade detection
- Test deviation calculation

#### 1.3 Error Handling Tests
- Malformed JSON (truncated, invalid syntax)
- Missing required fields
- Extra unexpected fields
- Empty files
- Very large files

### Layer 2: EA-Side Tests (Manual, MT4)

These require a running MT4 terminal.

#### 2.1 Manual Verification
- Install EA on MT4 demo account
- Verify `portfolio_status.json` is written with correct format
- Verify `trades.json` is appended on trade events
- Verify atomic writes (no partial JSON)
- Verify file updates at configured interval

#### 2.2 MT4 Strategy Tester
- Use MT4's built-in backtester to validate EA logic
- Verify trade detection (open/close/modify events)
- Verify strategy parameter capture

### Layer 3: End-to-End Test

- Start MT4 with EA running
- Start Certus app
- Verify Certus reads EA files and displays data on dashboard
- Verify real-time updates when trades occur
